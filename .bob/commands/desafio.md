- nivel: "$2" (valores válidos: iniciante | intermediario | avancado)

# ⚡ Desafio: <titulo>

**Tecnologia:** <tecnologia> | **Nível:** <nivel>

## Enunciado
<descricao completa do desafio>

## Exemplo
**Entrada:**
```
<exemplo_entrada>
```
**Saída esperada:**
```
<exemplo_saida>
```

## 💡 Dicas
- <dica 1>
- <dica 2>
- <dica 3>
